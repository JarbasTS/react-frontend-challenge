# 📚 Libris

Gerenciador de biblioteca pessoal que consome a [Google Books API](https://developers.google.com/books/docs/v1/using): autenticação simulada, busca com filtros e paginação, estante persistida e página de detalhes do livro.

Implementação do case [Libris](./cases/02-libris.md) do desafio técnico para Desenvolvedor React Pleno.

## Documentação

- **[ARCHITECTURE.md](./ARCHITECTURE.md)** — estrutura de pastas, autenticação sem backend, desafios com a API do Google Books e decisões/trade-offs.
- **[INSTRUCTIONS.md](./INSTRUCTIONS.md)** — como instalar, configurar variáveis de ambiente, rodar em desenvolvimento, testar e gerar o build de produção.

## Stack

React 18 + TypeScript (strict) + Vite · TanStack Query, Router, Form e Table · Zustand · Shadcn/ui + Tailwind CSS · Zod · Vitest + React Testing Library.
